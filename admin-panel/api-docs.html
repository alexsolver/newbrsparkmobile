Esta página reflete as rotas expostas pelo backend em admin-panel/backend/src/index.js e pelos routers em routes/. A especificação OpenAPI é gerada por admin-panel/scripts/build-openapi.js — após alterar rotas, execute npm run openapi na pasta admin-panel/backend.

Admin: obtenha JWT com POST /api/auth/login e use Authorize → bearerAdmin.
App: POST /api/login ou POST /api/register → bearerApp. Rotas públicas não exigem cabeçalho Authorization.
