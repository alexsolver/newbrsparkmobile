Visão IA - YOLO
Visão IA
○ Desconectado
Só o servidor BrSpark (Node) chama este URL — o app do técnico nunca abre este endereço diretamente; o telemóvel fala sempre com a API BrSpark (/api/checklists/vision/analyze), e o Node reencaminha o multipart para o YOLO. Pode ser URL público (ex.: http://vpn.lansolver.com:8001/analyze) ou na LAN. O serviço deve aceitar POST multipart com media, questions (JSON) e schemaVersion. Se o teste devolver 405 com página nginx, o path não aceita POST ou falta proxy_pass para a API.
