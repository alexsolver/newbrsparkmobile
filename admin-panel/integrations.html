Google Maps Platform
Mapas / Routing
○ Desconectado
Chave de API com Routes API (Compute Routes) ativa e faturação no Google Cloud. O app móvel chama apenas o BrSpark (POST /api/maps/google/route-metrics com JWT) — a chave fica no servidor. Cotas: limite mensal no plano (quotaGoogleMapsRoutesPerMonth, -1 = ilimitado, 0 = desligado) e teto opcional por organização em PATCH /api/tenants/:id/features com { "features": { "googleMaps": { "monthlyRouteRequestsMax": 5000 } } } (o menor valor entre plano e tenant vence).

Visão IA - YOLO
Visão IA
○ Desconectado
Só o servidor BrSpark (Node) chama este URL — o app do técnico nunca abre este endereço diretamente; o celular fala sempre com a API BrSpark (/api/checklists/vision/analyze), e o Node reencaminha o multipart para o YOLO. Pode ser URL público (ex.: http://vpn.lansolver.com:8001/analyze) ou na LAN. O serviço deve aceitar POST multipart com media, questions (JSON) e schemaVersion. Se o teste devolver 405 com página nginx, o path não aceita POST ou falta proxy_pass para a API.
Visão IA - Moondream
Visão IA
○ Desconectado
Só o servidor BrSpark chama a API Moondream (POST …/v1/query) com a imagem em base64 e cada pergunta do checklist. Obtenha a chave em moondream.ai. Predefinição: se Moondream e YOLO estiverem configurados e o tenant não tiver preferência em tenant.features.visionDetectionEngine, usa-se Moondream. Para forçar o proxy YOLO, defina visionDetectionEngine: "yolo" (PATCH /api/tenants/:id/features). Se só um dos dois estiver configurado, usa-se esse.
