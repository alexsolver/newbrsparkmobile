Dados pessoais
Reconhecimento facial — fotos base

Envie várias fotos nítidas do rosto (frente, ligeiras variações de ângulo ou iluminação) para o motor de reconhecimento usar como referência. Formatos: JPEG, PNG ou WebP; até 12 imagens, máx. 5 MB cada. Estas imagens são distintas da URL de avatar.

Envia o avatar (URL) e estas fotos base ao serviço Recognition do CompreFace (subject = tenant:utilizador). Necessita integração ativa em Integrações.

Horários de trabalho (prestador)
