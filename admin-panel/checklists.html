▸ Ajuda: navegação por seções no app (lista vs um a um)

Navegação no app — Em cada seção, no painel de propriedades à direita, escolha lista com scroll ou um campo de cada vez. O app junta as seções num scroll único quando todas são lista; se alguma for "um a um", usa telas por etapa. Formulários antigos só com "seguir global" continuam a usar o modo guardado no JSON até definir modo por seção.

Com uma única seção, o menu de etapas é ignorado no app. Com hub ativo e várias seções só em lista, o app mostra uma etapa de cada vez em vez de um scroll único.
